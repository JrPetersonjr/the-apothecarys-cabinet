🚀 Deploy & Host The Apothecary's Cabinet

Deploy your high-conversion e-commerce site to any web hosting platform in seconds.

One-Click Production Package

The website is completely self-contained with zero server dependencies. All CSS, JavaScript, interactive shopping cart, direct payment modals, and printable invoice engines run locally in the customer's browser.

Directory: /mnt/nvme0/AIRLOCK/WebStudio/templates/apothecary/
Deployment Options
Option A: Netlify or Vercel (Recommended)
Drag the templates/apothecary folder directly into the Netlify Drop dashboard for instant SSL and global CDN hosting.
Option B: GitHub Pages
Commit the folder to a GitHub repository and turn on Pages in repository settings.
Option C: Local In-Store Kiosk / POS
Run python3 -m http.server 8080 inside the folder to host it on an in-store iPad or local network terminal.
